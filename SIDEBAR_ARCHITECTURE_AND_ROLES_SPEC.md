CUSTOMS & CARGO MANAGEMENT SYSTEM

Sidebar Structure & Navigation Report

1. Kanuni Kuu ya Sidebar

Mfumo una workflow ya hatua 1–11, lakini hatupaswi kuweka kila Step kama button kwenye sidebar.

Sidebar itaonyesha modules kulingana na role ya user. Ndani ya module ndipo user ataona jobs, hatua za workflow, forms na actions zinazomhusu.

Mfano:

«Step 3 Assessment & Declaration si lazima iwe button ya sidebar kwa kila user.
Kwa Customs Declarer, inakuwa ndani ya Declarations.»

Hii itafanya mfumo uwe rahisi kutumia na kupunguza buttons zisizo za lazima.

11. ATTENDANCE SI LAZIMA IWE SIDEBAR YA KILA USER

Attendance ni function ya mfumo, lakini si lazima kila role apewe button yake.

Documentation Officer

"Dashboard | New Intake | Documents | Clients"

Clock-in inaweza kuwa button ndogo juu ya dashboard, mfano:

«🟢 Clock In»

Sio lazima iwe:

«Attendance»

kwenye sidebar.

Field Agent

Anaweza kuwa na:

«📍 Field Clock In»

kwenye dashboard.

Mfumo ukitumia GPS/geofencing unaweza kuthibitisha location kabla ya kuruhusu clock-in.
